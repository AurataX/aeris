# Data analysis

60 prompts: 15 interaction briefs, each in Explore, Build, Review and Validate modes.

## F0301 — Workspace composition / Explore

Act as a product and interaction designer. Produce an original visual direction and a concrete storyboard; do not implement code in this pass.

Product context: Data analysis. The user is an analyst exploring a retention dataset. The concrete object is Retention / October cohort.

Assignment: Compose the workspace around the job: filter a cohort and compare two chart views. Use Retention / October cohort as believable content. Compare an atmospheric home with a focused working view. Locate global navigation, the current object and the next useful action before choosing decorative surfaces.

Required states: Show what remains stable when the user enters focused work. Include one small-screen composition and a content-heavy state.

Domain constraint: Keep axis units, active filters and stale-data status visible; never animate values as if interpolated data were real.

Visual direction: ink, frosted silver and muted teal; a low-detail horizon outside charts.

Interaction contract: Keep the working surface calm, readable and original. Do not copy the supplied student dashboard or invent decorative metrics. Preserve every required feature through a discoverable location. Use a stable dock only when it fits the task, restrained glass and metallic accents, and semantic SVG icons. Acknowledge input immediately; settling motion must not postpone the action. Treat duration values as tuning hypotheses, not performance proof. Provide keyboard, touch and reduced-effects behaviour.

Acceptance: A new user can identify the current object, the next action and the way back without opening a menu.

Output: Deliver two meaningfully different compositions, choose one with a task-based explanation, and give a high-fidelity image-generation prompt. Include a transition storyboard with start, response and settled states. A still image cannot prove smoothness or speed. Use fictional sample data and label it.
